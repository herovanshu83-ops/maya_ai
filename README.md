## ✨ Key Features

<p align="center">
  <table>
    <tr>
      <td width="50%">
        <h3>🗣️ Continuous Voice & STT</h3>
        Real-time speech-to-text transcription with custom acoustic echo suppression and automatic retry loops.
      </td>
      <td width="50%">
        <h3>⚡ Firebase Generative AI</h3>
        Integrates Gemini 2.5 Flash (<code>generateContentStream</code>) to stream intelligent responses instantly.
      </td>
    </tr>
    <tr>
      <td>
        <h3>🔊 TTS & Floating Overlays</h3>
        Natural voice feedback combined with a floating overlay service for system-wide accessibility.
      </td>
      <td>
        <h3>🛠️ Intelligent Actions</h3>
        Automatically classifies user intent to execute system controls, open apps, manage routines, and recall memories.
      </td>
    </tr>
    <tr>
      <td>
        <h3>🗄️ Offline-First Storage</h3>

      </td>
      <td>

        Sleek dark-themed futuristic UI, dynamic color palettes, custom launcher icons, and smooth animations.

## 🏗️ Architecture & Tech Stack

| Layer | Technology |
| :--- | :--- |
| **UI Framework** | Jetpack Compose & Material 3 |
| **Architecture** | MVVM (Model-View-ViewModel) with StateFlow |
| **AI Integration** | Firebase AI Logic (`com.google.firebase:firebase-ai`) |
| **Database** | Room Database with KSP |
| **Async Processing** | Kotlin Coroutines & Flows |
| **Testing** | Robolectric & JUnit |
